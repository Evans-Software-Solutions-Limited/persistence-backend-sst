# Integrated acceptance and pilot protocol

Pending evidence; use authorized test accounts and sources. Record commit/runtime, synthetic versus real inputs and source/model/metric versions. Nothing below has been executed during this research session.

| Scenario                                                                                         | Required evidence                                                                                                    |
| ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| Clear PDF, rough photo, URL and voice describing the same plan                                   | Same reviewed prescriptions and dates, source evidence, no invented missing details.                                 |
| Six-week plan with fixed weekdays, a deload, changed loads and multiple sessions/day             | Explicit schedule round-trips; no repetition/spacing rewrite; correct athlete-local dates.                           |
| Conflicting handwritten numbers, “five, actually six”, missing units and ambiguous squat variant | Visible question/correction; no accidental confident match or silent numeric clamp.                                  |
| Source contains unknown training fields, inaccessible URL or oversized scan                      | Bounded actionable failure or unresolved draft; no silent truncation or privacy bypass.                              |
| Premium Plus, Premium, every paid coach tier and coached free client                             | Exact capability matrix; personal benefits do not grant coach APIs.                                                  |
| Accept/retry/response loss, duplicate worker and cancel race                                     | One coherent accepted asset/receipt, no half-programme or duplicate metering.                                        |
| Two users upload identical private source; source expires                                        | Owner isolation, no cache existence leak, enforced cleanup.                                                          |
| Import catalogue twice while owner edits a target                                                | Duplicate decisions/receipts stable; stale merge conflicts; no hidden overwrite.                                     |
| Coach assigns/revises while athlete starts/logs                                                  | Prescribed snapshot and completed history immutable; old runtime fails clearly where unsupported.                    |
| Coach/athlete open same review scope/version                                                     | Same completed/expected count, exclusions, interval and asOf.                                                        |
| No plan, rest day, skipped/cancelled session, late/offline log, duplicate completion             | Correct null/rate/coverage; gym-habit metric remains separate.                                                       |
| Private coach notes, another coach relationship and revoked consent during inference             | No leakage through DTO, prompt, cache, jobs or comments.                                                             |
| Explicit Design mode with incomplete constraints                                                 | Proposed fields/assumptions visible; missing material context blocks assign; import mode never generates implicitly. |
| Web keyboard/mobile permission denial, interruption and reconnect                                | Recoverable draft, usable fallback, no auto recording or phantom success.                                            |

Proposed pilot: five coaches and five Premium Plus athletes compare representative manual entry with import/design, including review and correction. Record usable-plan creation time, critical correction count, import-to-save, save-to-first-log, repeat use and shared-review response time. Target ≥50% median reduction in authoring time without silent critical changes; report sample size and misses. Participants are not recruited and no customer contact is authorized by this document. Actual per-modality accuracy/cost and compatibility gates remain separate from pilot satisfaction.
