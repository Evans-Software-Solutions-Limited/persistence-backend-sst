## What the request log found

- `/subscription-tiers` at +2 ms: `useSubscriptionTiers` gated on a resolved
  user and its own auth instance had not resolved that early. Fixed with a
  process-level cold-start flag set from the app shell's first render.
- `/notifications` at +79 ms: `useUnreadNotificationCount`'s focus callback
  changes when the session resolves, re-running the focus effect past a
  per-instance first-focus latch. Fixed with a per-user latch. The AppState
  listeners in both unread hooks also stop treating iOS's launch
  inactive → active flip as a return from the background.

## Bootstrap latency

warm. Sections run three at a time because the DB pool is four connections;
